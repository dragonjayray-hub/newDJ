# 古风 DJ 曲目工坊

一个可直接打开的单页原型：把歌曲拖入音频栏后，界面会生成按小节排布的和声地图，悬停小节可查看该小节内的一个或多个和弦；同时提供低切、降速、降调控制，以及会在每小节第 1、3 拍落点的 Kick one-shot 条。

## 运行

无需安装依赖：直接用浏览器打开 `index.html`，或执行：

```bash
python3 -m http.server 8080
```

再访问 `http://localhost:8080`。

## 当前浏览器原型的边界

- 已加载的歌曲可直接播放、调节播放速度，并由 Web Audio `BiquadFilterNode` 实时执行高通低切。
- 文件名会驱动一组可演示的速度、调性和小节和声结果；生产版本应由分析服务替换为真正的 beat/downbeat、key 和 chord 识别结果。
- 浏览器原生音频 API 没有高品质、独立的保调变速/变调导出器。因此“降调”在此原型中作为工程参数保存和展示，而不是假装使用低质量重采样完成它。

## 生产 DSP 建议（2026）

不存在所有素材和所有指标下唯一“最好”的变速变调算法；应按授权方式选择：

1. **商业成品优先：zplane élastiquePRO v3**。它是音乐制作软件中广泛采用的高质量相位锁定变速/变调方案，适合最终离线导出。
2. **开源、本地优先：Rubber Band R3 引擎**。它的 R3 细节引擎专为更高保真度的离线音乐处理设计，适合作为桌面端渲染层。
3. **实时预览**：使用 R2/WSOLA 等低延迟路径预听，导出时切换至 R3 或 élastiquePRO；不要直接用 `playbackRate` 作为最终古风降速降调的结果。

建议的生产管线为：上传文件 → Essentia/Madmom 做 BPM、downbeat、key 与 chord 识别 → 将置信度与小节编号写入工程 JSON → 由 Rubber Band R3 或 élastiquePRO 离线渲染速度和半音参数 → 以检测到的 BPM、拍号与调性量化触发 one-shot。
